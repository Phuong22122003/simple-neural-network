# simple-neural-network

A lightweight neural network library implemented from scratch in Python.  
Includes core layers like `Dense`, `Embedding`, `Attention`, implement optimizers like `Adam`, `SGD`, and supports basic training for tasks such as **text generation**, **MNIST classification**.

---

## Features

- Fully implemented in **pure Python**, no deep learning framework dependencies
- Core layers:
  - `Dense`
  - `Embedding`
  - `Attention`
- Customizable:
  - Model structure
  - Optimizers (SGD, Adam)
- Training loop from scratch
- Simple example for **text generation**. Implement in LLM.ipynb file.
- Packaged and published on **PyPI**
